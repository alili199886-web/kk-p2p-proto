赛事大厅 · 开盘坐庄需求标注

本期在 IM 既有赛事与盘口范围内，升级为「私盘模式按赛事开盘坐庄」。原比赛与既有投注项卖出完全不受影响。

开盘入口

  • 入口位于 P2P 已生效联赛下，每场比赛行时间/场次信息旁的「开盘」按钮，不与赔率列重叠。
  • 开盘范围 = IM 在售且未开赛的赛事，含今日盘与早盘；滚球（已开赛）不展示开盘入口，切换到滚球页签时该页全部赛事均无开盘入口。
  • 互斥仅限同一会员：同一会员对同一场比赛，开盘坐庄与投注项卖出二选一——本人已有进行中的私盘时该场「卖出」入口置灰，本人已有该场投注项卖出时「开盘」入口置灰。不同会员互不影响：该场官方盘已有其他会员的 P2P 挂单时，仍可正常开盘；私盘档位只在私盘内成交、官方盘卖单簿只含投注项卖出档位，两者押金池、撮合与结算彼此独立，新开私盘不影响官方盘上已有 P2P 挂单的购买。
  • 提交时二次校验：开盘弹窗打开后至点击「确认开盘」期间，若本人在该场挂出了投注项卖出，提交时拦截并提示「你对该场已有投注项卖出，不可再开盘」，弹窗关闭。
  • 赛事所属联赛需在可坐庄联赛白名单内，不在名单内不展示入口。
  • 庄家坐庄权限被运营关闭时不展示入口，存量盘不受影响。

私盘展示规则

  • 开盘 = 复制该比赛生成私盘，名称 = 原比赛名 + 庄家昵称（开盘弹窗设置，最长 12 字符，默认取上次值）。
  • 私盘紧随原比赛下方展示，右侧「私盘」标识（样式同 P2P 标识，替代其位置）。
  • 仅展示庄家开放的盘口：开放项显示庄单赔率（独赢为欧洲盘 = 港盘 + 1，让球/大小为港盘），未开放项显示 -- 置灰，单项封盘显示锁定态。
  • 可见性：盘为卖出中时展示；整盘售罄 / 已关闭 / 已结算后私盘从列表消失。
  • 多位庄家可各自对同一场比赛开盘，各生成独立私盘，按开盘时间排列；同一庄家同一比赛限 1 个进行中的盘。
  • 开盘与投注项卖出互斥：同一会员对同一场比赛，开盘坐庄与投注项卖出二选一。已有进行中的盘时，该场全部投注项的「卖出」入口置灰并提示「该场已开盘，不可再单独卖出」；已有该场进行中的投注项卖出时，该场「开盘」入口置灰并提示「该场已有投注项卖出，不可再开盘」。两者的「进行中」判定一致：卖出中、已封盘计入，已售罄 / 已关闭 / 已结算不计入。
  • 「进行中」的判定范围：卖出中、已封盘计入（私盘仍在列表或可恢复）；已售罄、已关闭、已结算不计入，庄家可对同一比赛再开新盘——售罄盘已从列表消失，不会造成重复占位。
  • 单场私盘展示上限 N 个（默认 5），超出折叠为「查看全部私盘」，折叠不影响卖单簿成交。
  • 筛选行「私盘」胶囊：开启后仅展示私盘。
  • 比赛卡片的队伍信息：每行为「球队图标 + 队名 + 红黄牌角标」，行右侧展示该队当前比分；黄牌为橙底白字方块、红牌为红底白字方块，牌数为 0 时该角标不展示。队名下方一行展示「直播图标 + 半场比分 + 角球图标与角球比分」，对应字段缺失时该项不展示、整行无内容时不占位。官方盘与私盘的这部分展示规则一致。
  • 私盘行版式与官方盘一致：标题行为私盘名称 + 右侧「私盘」标识；开赛时间展示在队名上方；盘口名称列头（全场 / 上半场 的 独赢、让球、大/小）与官方盘同位置同样式；「全部 N▸」入口展示在队名下方（与官方盘的「所有盘口 N▸」同位置）；底部翻页指示点与左右滑动切换全场 / 上半场的交互也与官方盘一致，与该场官方盘共用同一分页状态（官方盘切到上半场时，其下的私盘同步切换）。
  • 私盘的「全部 N▸」入口：赛事列表的私盘行只展示六类主玩法（全场 / 上半场 的 独赢、让球、大/小）。当私盘开了这六类之外的盘口（如进球、波胆、特殊玩法）时，展示「全部 N▸」（N = 该私盘开放的盘口总数）；点击进入盘口详情页，页面仅展示该私盘开放的盘口、按该私盘的庄单赔率显示，点击任一盘口即加入购物车并按私盘规则投注。私盘开放的盘口全部落在六类主玩法内时不展示该入口。

购物车（投注面板）

  • 形态：底部固定面板（约占屏高 58%），不使用弹窗、不对赛事列表加蒙层；面板打开时赛事列表仍可滚动、赔率格仍可点击，选中新投注项实时加入购物车。
  • 顶部：买入 / 卖出两个页签等分居中；右上角常驻关闭按钮（×），点击仅收起面板，已选投注项保留，可再次点击赔率格或购物车入口重新打开。不展示注单计数与清空图标。
  • 选中私盘投注项时隐藏「卖出」页签：私盘只承载开盘庄家本人的档位，其他会员不能往该私盘挂单，因此私盘投注项不支持卖出；若已停留在卖出页再选中私盘项，自动切回买入页；强行调用卖出页提示「私盘投注项不支持卖出」。关闭按钮在此场景仍保留。
  • 投注卡片：标题为「盘口 + 队名」（如 +0.5/1 瓦特福）；第二行「玩法 · [盘口类型]」；第三行「主队 VS 客队」；第四行「足球 · 联赛」。右上角为赔率与删除图标。
  • 档位表：该投注项存在不低于官方赔率的 P2P 档位时展示（档位 / 卖出赔率 / 可购额度 / 购买计划四列）；无此类档位时整块隐藏，输入框下方直接接数字键盘，按官方赔率投注。
  • 底部：自动接受任何赔率开关与说明入口、余额；按钮行为「串关 / 单关」与「投注 CNY 合计」（附最高可赢），不设「返回」按钮，收起面板走右上角关闭按钮。
  • 投注成功后：已投注的投注项自动取消选中、金额清空，购物车收起并回到赛事列表，再弹出注单确认；若仍有未投注的选中项，点「保留注单，继续投注」会重新打开购物车。

串关限制

  • 私盘投注项不参与串关：私盘项仍在串关页展示，置灰并标注「私盘投注项不支持串关，仅官方盘投注项可参与」，不计入组合、不计入串关资格判定。
  • 同场不可互串：同一场比赛的多个投注项不允许串关，包括「一个官方盘 + 一个私盘」这种组合（私盘复制自原比赛，视为同一场）。串关组合按原比赛去重，每场只取先选中的一项参与，其余置灰并标注「与已选投注项属同一场比赛，同场不可互串」。
  • 串关按钮激活条件：可参与串关的投注项需来自 ≥2 场不同比赛。购物车内只有同一场赛事时（无论官方盘或私盘），串关按钮置灰；已进入串关页但可串项不足 2 场时不生成组合行，提示「可串关的投注项不足 2 场，无法生成串关组合」。

开盘门槛（确认时逐条校验，任一不满足即拦截）

  • 开放盘口数 ≥ 3（min_items）
  • 盘押金 ≥ 1,000（min_deposit，整盘一笔，全部盘口共享）
  • 开赛前 10 分钟内禁止新开盘（freeze_minutes）
  • 门槛的前置与临界：IM 交集内可开盘口不足 min_items 时不展示开盘入口；账户余额需 ≥ 盘押金，等于时允许；封盘前置时间以服务端接收开盘请求的时间为准，不以客户端点击时间为准。

赔率格与卖单簿

  • 原比赛有庄家档位的盘口展示红点，变化实时刷新；私盘赔率格样式与官方盘一致，不做颜色区分。
  • 卖单簿按来源隔离：私盘的卖单簿只有「该开盘庄家的档位 + 官方无限档位」；官方盘的卖单簿只有「投注项卖出档位 + 官方无限档位」。三类档位不会同时出现在同一个卖单簿中。各自内部按赔率降序 → 同赔率卖出时间优先 → 官方固定最后。
  • 「私盘」与「P2P」标识互斥：私盘表示私人开盘，仅标注在私盘行；P2P 表示有会员对该场玩法项坐庄，仅标注在官方盘（原比赛与联赛头）。官方盘不展示私盘标识，两者不同时出现在同一对象上。
  • 展示范围：赔率低于官方赔率的档位不展示（视为已下架，不可成交）；赔率不低于官方的档位全部展示，不做数量截断。
  • 可见高度：卖家档位最多可见 5 档，超过 5 档时区域内出现滚动条，滚动查看其余档位；官方档位固定在最后一行，不参与滚动。

我的卖出 · 需求标注

私盘与既有投注项卖出并存，分页签展示，筛选对两个页签同时生效。

结构

  • 顶部为两个页签（样式同买单列表）：投注项卖单（默认选中，展示官方盘的投注项坐庄数据）与私盘（展示开盘坐庄的盘卡片）。
  • 页签下方为筛选区，一排展示两个下拉：
    · 时间筛选（默认「今天」）：今天 / 昨天 / 近7天 / 近30天 / 自定义；选择「自定义」弹出自定义时间弹窗（与买单已结算的筛选弹窗一致），应用后下拉文案显示所选区间；
    · 状态筛选（默认「全部」）：全部 / 卖出中 / 已售罄 / 已结算 / 已关闭。
  • 筛选区下方为四列汇总：总卖出 / 进行中 / 已消费 / 总结算盈亏（盈利绿色、亏损红色、不输不赢黑色，符号与数值同行不换行）。

私盘卡片字段

  • 联赛、「私盘」标识、状态标签、私盘名称（与赛事列表中该私盘的名称一致，即「原比赛名 · 庄家昵称」，不使用原比赛名）、盘号、开放项数、总押金、收单进度条、已收 / 押金、查看详情。
  • 私盘不展示分享按钮，暂不支持分享；投注项卖单的分享入口不受影响。
  • 卡片不展示「私盘」标识（私盘列表本身已表明来源）；已结算盘在该位置（联赛名右侧、状态标签左侧）展示盘净盈亏，赢绿输红、不输不赢黑色，带正负号且同行不换行。

历史数据

  • 上线前既有的投注项卖出庄单不受影响，自动归入「投注项卖单」分段。

开盘详情与控盘 · 需求标注

庄家对自己私盘拥有完整控盘能力：动态增减盘口、调水、单项封盘、补充额度、停止收单。

入口：我的卖出 → 私盘页签 → 点击盘卡片「查看详情」。庄家对自己私盘的全部控盘操作都在本页完成。

页面结构（自上而下）

  • 顶栏：返回（回我的卖出）、标题「开盘详情」、右侧盘状态标签（卖出中 / 已售罄 / 已结算 / 已关闭）。本页不提供分享入口。
  • 状态横幅：仅在已关闭时展示，提示「已停止收单，卖出单已从卖单簿下架，等待赛事结算，未消费押金结算后退回」。已结算不展示顶部横幅，盈亏在列表汇总与各投注项庄单的输赢标签上体现。
  • 赛事信息卡：主队 vs 客队、联赛 · 开赛时间、开盘时间、自动封盘设置（开赛前 N 分钟）。
  • 四列汇总：总押金 / 已收单 / 子单数 / 状态。
  • 投注项庄单列表：标题「投注项庄单(N)」，逐项展示卡片。
  • 底部操作区：盘级操作按钮，按状态变化（见下）。

庄单卡片字段

  • 投注项名 + 单项状态标签：单项状态跟随盘状态——盘为卖出中时各投注项均显示「卖出中」，盘为已售罄时各项均显示「已售罄」，盘已关闭时各项显示「已关闭」；单项被庄家手动封盘时该项显示「已封盘」，不随盘状态；盘已结算时标签改为该投注项的输赢结果（赢绿 / 输红 / 走水灰），不再显示「已结算」。
  • 庄单赔率：绿色显示。确认开盘后固定，不随官方赔率联动。
  • 官方当前赔率：仅作参考不参与计算；当庄单赔率低于官方赔率时追加红字「低于官方」提示（此时该档位已从卖单簿下架，不可成交）。
  • 已收金额、剩余可卖额度（标注「共享盘押金」，提示额度来自整盘共享池）。
  • 单项操作：调水、封盘 / 恢复。
  • 子单列表：标题「子单数据(N)」，默认收起，点击标题行展开 / 收起（右侧显示「展开 ⌄ / 收起 ⌃」）；每次进入详情页默认全部收起。无成交时显示「子单数据(0)：暂无成交」，不可展开。每笔两行——第一行「会员」标签 + 买家 ID + 成交金额 + 成交赔率；第二行成交时间 + 结算金额（已结算，赢绿输红；未结算显示「未结算」）。

底部操作区（按盘状态）

  • 卖出中 / 已售罄：展示「新增盘口」「补充额度」「停止收单」。
  • 已结算 / 已关闭：无任何控盘操作，底部操作区整条隐藏；返回统一走左上角返回按钮。

调水

  • 新庄单赔率 = 当前庄单赔率 + 调整点位；点位可为负，最多两位小数，新赔率必须大于 0。
  • 官方当前赔率仅作参考，不参与计算；庄单赔率确认后固定，不随官方联动。
  • 已成交子单按原成交赔率结算，调水只影响后续新成交。
  • 调水不影响已占用押金：已成交子单的押金占用按成交时的庄单赔率锁定，不随后续调水重算；剩余押金仅因新成交、补充额度、结算三类事件变化。
  • 实时生效、卖单簿实时重排；单项 10 秒内限调 1 次，超频拦截。
  • 调水频次与幅度：10 秒限频为单投注项维度，同一盘内不同盘口可各自独立调整；单次调整点位绝对值上限、以及调整后赔率的绝对上限由配置参数控制，超出即拦截，防止极端赔率。

封盘 / 恢复（单投注项级）

  • 封盘后该项档位从卖单簿下架、暂停收单，卖出单保留，官方档位不受影响；开赛前可随时恢复，二次确认后执行。
  • 整盘自动封盘（到点或开赛）等价于全部投注项同时封盘。
  • 自动封盘触发后该设置即失效，恢复开盘后不会被再次自动封盘；需重设才再次生效。

新增 / 移除盘口

  • 新增：盘进行中可从 IM 交集内未开放的盘口勾选新增，按新增时官方港盘赔率 + 上浮点位定价，共享押金池，无需追加押金（剩余押金为 0 时提示先补充额度）。
  • 移除：仅该盘口无任何成交时可移除；盘押金为共享池，不因移除变动、不退款。
  • 移除后开放盘口数仍需满足 ≥ min_items，低于门槛拦截并提示「如需清空请使用停止收单」。
  • IM 侧被动下架：某盘口被 IM 下架时该投注项自动置为已封盘并从卖单簿移除，已成交子单按 IM 返回结果处理；若开放项因此低于 min_items，盘不自动关闭、可继续收单（门槛只约束开盘与主动移除，不回溯被动变化），但该盘口不可再新增。

补充额度 / 停止收单（盘级）

  • 补充额度：输入一笔追加金额，实时预览追加后押金与新增预计可卖额度；追加进入共享池，全部盘口剩余可卖同步扩大，赔率与状态不变；已售罄追加后回到卖出中。
  • 停止收单：二次确认（明示不可逆）后全部档位立即下架、私盘从列表消失、盘置为已关闭；已成交子单正常结算，未消费押金结算后退回。

押金与结算

  • 庄单赔率 = 开盘时官方港盘赔率 + 上浮点位（加法，可为负），确认后固定。
  • 预计可卖额度 = 盘押金 ÷ 最高卖出赔率（最保守口径）。
  • 剩余押金 = 盘押金 + 补仓 − Σ(成交金额 × 对应庄单赔率)；各盘口实时可卖 = 剩余押金 ÷ 该项赔率，任一盘口成交同步收缩其他盘口额度。
  • 每笔子单占用 = 成交金额 × 庄单赔率，即最大赔付责任，保证不穿仓；剩余押金归零即整盘售罄。
  • 额度死区：某盘口实时可卖额度低于该玩法最小投注额时，该项置为不可买（展示为额度不足的锁定态），避免「显示有额度但买不了」；全部开放项均不可买时整盘转为已售罄。
  • 并发控制：可卖额度以服务端为准，同一盘的成交请求串行处理，额度校验与扣减在同一事务内完成，杜绝多盘口并发成交导致的超卖穿仓；校验失败提示「额度已被其他买家占用，请重新输入金额」。
  • 结算：子单按买家视角，庄单盈亏 = 子单结算总和 × (−1)；押金全额解冻退回，盈亏逐项入账。
  • 分段结算：按投注项所属时段分别结算。上半场玩法在上半场结束并由 IM 返回结果后即结算，对应子单的押金占用同步释放、剩余押金回升、其余盘口可卖额度随之扩大；全场玩法待全场结束结算。盘在全部开放项结算完成后整体转为已结算。
  • 赛事改期：以 IM 返回为准。IM 保留赛事仅变更开赛时间时，盘顺延继续收单，自动封盘按新开赛时间重算；IM 取消赛事时按赛事取消处理，子单全额退款、押金全额解冻。
  • 抽佣费率由 APISYS 下发，不在本系统配置；庄家按单净盈利抽佣，买家侧抽佣基数 = 购买 P2P 盈利 − 购买官方盈利，由结算系统扣除。
  • 费率异常兜底：APISYS 未返回费率或返回非法值（小于 0 或大于 100%）时不采用该值，按平台兜底费率（配置项）结算，并记录异常日志告警，不阻断结算。
  • 押金占用提示：开盘前常驻灰字「押金自开盘起冻结，至赛事结算后解冻退回」，早盘额外提示预计冻结时长。

投注项卖出详情 · 需求标注

入口：我的卖出 → 投注项卖单页签 → 点击卖单卡片。对应既有的「单投注项卖出」形态，与开盘坐庄的私盘详情是两个独立页面。

页面结构

  • 顶栏：返回、标题「庄家卖出详情」、右上角分享入口——仅「卖出中」状态展示，部分成交、已售罄、已封盘、已关闭、已结算均隐藏；卖单列表卡片上的分享图标同此规则。
  • 赛事卡：联赛 + 状态标签；主队 VS 客队（队名完整展示，不截断）；玩法标签 + 投注项。
  • 最终输赢：仅已结算展示，大字号居中，赢绿输红。
  • 三列指标：剩余额度 / 已收单 / 上浮点位。
  • 消费进度：已收单 ÷ 总额度，进行中蓝、已结算绿、已关闭灰。
  • 基础信息：抵押类型、抵押金额（旁有感叹号图标，点击查看押金变动记录）、卖出赔率（港盘）、总额度、子单数、卖出时间。
  • 会员买单列表：逐笔展示买家、成交金额、成交时间；已结算时追加每笔结算金额、平台抽水与卖出返回。
  • 底部操作：卖出中 / 部分成交 / 已售罄时展示「补充押金」「停止收单」；已结算、已关闭时无操作按钮。

与开盘详情的区别

  • 本页是单个投注项的卖出挂单，押金独立、只对应一个盘口；开盘详情是整盘，押金共享、含多个投注项庄单。
  • 本页支持分享挂单；私盘暂不支持分享，开盘详情无分享入口。
  • 本页无调水与新增 / 移除盘口能力，只能补充押金或停止收单。

买单（注单记录）· 需求标注

投注信息区

  • 标题格式：让球用亚盘写法「主 -0/0.5」「客 +0/0.5」；波胆直接显示投注比分「1-3」；独赢/大小显示选项文字「主 胜」「大 1.5」。
  • 玩法标签行：[滚球标签] 时段 · 玩法名称 @赔率 (盘口类型)；滚球注单才显示滚球标签，赛前不显示任何类型标签。
  • 下方为队名行（主队 vs 客队）与联赛行；右上为输赢状态印章（圆形）。

金额区（分隔线隔开）

  • 投注金额固定展示；输赢正数绿色带「+」、负数红色带「−」、走水显示灰色 0.00。

信息区（左灰标签 + 右对齐内容）

  • 比分：结算依据比分高亮 + 参考比分，依据随玩法时段走（全场玩法依据全场、上半场玩法依据上半场）；仅已结算显示。
  • 投注比分：仅波胆注单显示。
  • 下注时：滚球显示即时比分（绿色），赛前显示「赛前」。
  • 注单号（带复制图标）与投注时间：始终显示。

结算结果

  • 五种：赢 / 赢半 / 输 / 输半 / 走水，以圆形印章展示，赢系绿、输系红、走水灰。
  • 串关：标题 + 总赔率 + 印章；每条腿展示投注项、赔率、玩法行、赛事、下注时比分、结算比分与单腿输赢。

盘口详情 · 需求标注

  • 入口：比赛卡片底部的「全部」或「P2P」，两个入口进入同一页面，内容完全一致，不做筛选差异。
  • 「全部 N」的 N 为该场投注项数量，与本页赔率格总数一致；「P2P N」的 N 为该场存在 P2P 庄单的投注项数量。
  • 顶栏：返回、联赛名、刷新、收藏；赛事横幅含主客队、状态、开赛时间、动画直播入口。
  • 玩法 Tab：全部 / 让球 / 大小 / 进球 / 半场 / 特殊，切换后仅展示对应分组；每组可折叠，主客两列并排。
  • 赔率格规则与赛事大厅一致：有更优 P2P 档位时展示最高 P2P 赔率并带红点（红点常驻，不因点击消失，仅当无高于官方的档位时自动消失）；点击即选中并加入购物车。

P2P 挂单分享 · 需求标注

分享对象为单个投注项庄单。体育侧无原生 App，H5 运行在三类容器中。

容器与按钮展示

  • 金刚 App WebView、现金盘内嵌：注入了 IM SDK，展示「分享到金刚」。
  • 手机浏览器：无 SDK，不展示「分享到金刚」。
  • 「分享到 TG」与「复制链接」所有容器常驻；TG 走 t.me/share/url 网页链接，未安装 TG 时打开网页版，不白屏。
  • 浏览器无法预判 App 是否已安装，故以容器判定代替安装检测。

链接与落地

  • 链接结构：/p2p/s/{庄单ID}?m={商户标识}，公开可访问、无需登录；m 决定接收方点击后回到哪个平台的体育入口。
  • 内容页展示 LOGO、赛事、玩法、投注项、卖出赔率、庄家、挂单状态、来源平台；不展示剩余可卖额度等资金信息；每次打开实时拉取，不用缓存。
  • 有效（卖出中含部分成交、有可卖额度、赛事未开赛）：进入该赛事、选中投注项、弹出购物车。
  • 失效（售罄/封盘/关闭/结算/已开赛）：回赛事页，不开购物车，toast「当前订单已失效，请选择其他p2p订单进行购买」。
  • 赔率变化导致下架（赔率低于官方）：回赛事页后弹窗「该 P2P 挂单已下架」，单按钮「我知道了」。
  • 开盘庄单的分享：开盘坐庄盘内的每个投注项庄单同样支持分享，入口与规则同投注项卖出。失效判定在原有 5 种之外追加「所属盘已封盘 / 已关闭 / 已结算」；落地仍进入原比赛该投注项并弹出购物车，该庄家档位在卖单簿中正常可见可成交，不单独跳转私盘。

冠军玩法 · 需求标注

入口：赛事页顶部「冠军」页签，位于早盘与串关之间。以下规则部分为初稿提案，文末列出待确认项。

玩法定义

  • 投注对象是整个赛事或联赛的最终结果，不是单场比赛。典型玩法为联赛冠军、小组头名、降级、最佳射手。
  • 一个赛事对应一个冠军盘口，盘口下为多个候选项（球队或球员），各候选项赔率独立。
  • 结算周期长，从开盘到结算可能跨越整个赛季。

列表与展示

  • 三级结构：状态组（未开赛）→ 地区 → 联赛盘口 → 候选项，每级独立折叠。
  • 状态组与地区行右侧显示该层级下的盘口数量，不是球队数量。
  • 盘口命名格式：联赛名 + 赛季 + 空格连字符 + 玩法名，如「英格兰超级联赛2026/2027 - 冠军」。
  • 展开盘口后，首行为灰底的「截止日期/时间：DD/MM/YYYY HH:mm」。
  • 候选项按赔率从低到高排列，左侧队徽加名称，右侧灰底圆角赔率块，一次性展示全部，不做条数截断。
  • 赔率统一使用欧洲盘，保留两位小数。
  • 候选项已无夺冠可能时从列表移除，不再展示，也不可投注。会员已投注的注单仍可在买单中查看。
  • 地区默认全部展开，盘口默认仅展开第一个，其余收起。地区行不提供置顶功能。

投注规则

  • 冠军注单只能单注，不支持串关，不可与任何其他投注项组合。
  • 冠军盘口不支持坐庄，不进入 P2P 卖单簿，赔率格不显示红点。冠军页签下隐藏「P2P」与「私盘」两个筛选，联赛、时间、筛选、收起保留。
  • 冠军注单不可作为订单抵押物挂出庄单。
  • 同一赛事下可同时投注多个候选项，各自独立成单。
  • 投注成功后赔率锁定为下注时赔率，后续盘口赔率变动不影响已成交注单。

赔率与封盘

  • 冠军赔率随赛程进展由操盘系统实时调整。
  • 封盘时点为该赛事最后一轮首场比赛开赛前，具体提前量由操盘配置，不做固定写死。
  • 封盘后不再接受新投注，盘口保留在列表中并标注「已封盘」，赔率置灰不可点，不从列表移除。
  • 已成交注单不受封盘与赔率变动影响。

结算与异常

  • 赛季结束、冠军产生后统一结算，命中候选项按锁定赔率派彩，未命中注单全额输。
  • 赛事取消或未完赛：全部注单按原金额退款。
  • 候选项中途退赛：该候选项的注单退款，同一赛事其余注单不受影响。
  • 赛事延期：注单保留等待实际结果，不自动退款。

汇总报表 · 需求标注

入口：我的 → 我的卖单下方「汇总报表」。以下为该页全部规则，供研发与测试对照。

统计口径

  • 已结算数据按结算时间归集，不按投注时间或挂单时间。
  • 总盈亏只统计已结算，未结算注单与进行中庄单一律不计入。
  • 买单盈亏与卖单盈亏均取扣除平台抽佣后的净额，抽佣比例由后台配置。
  • 买单直接读取注单的输赢字段，不在本页做任何佣金计算。买方抽佣由已上线的结算功能处理，算法为「购买 P2P 订单盈利 − 购买官方单盈利」的差额乘以抽佣比例，结算时已从输赢中扣除。
  • 已关闭庄单：未售出部分的押金原路退回，该部分不计算盈亏；已售出部分仍按正常结算计入盈亏。
  • 完全未售出即关闭的庄单，押金全额退回，盈亏为 0，计入卖单笔数但不影响盈亏。
  • 赛事结算后，庄单状态由「已关闭」转为「已结算」。因此本页取数条件为状态等于「已结算」，无需额外纳入「已关闭」。

时间筛选

  • 预置四项：今天 / 昨天 / 本周 / 本月，默认本周，周起始为周一。
  • 右侧「筛选」点击直接弹出日期弹窗；筛选二字不带选中态。
  • 弹窗约束：日期格式 YYYY-MM-DD；开始不得晚于结束；结束不得晚于今天；跨度上限 1 年。违反时 toast 拦截，不提交。
  • 默认值：开始取区间内最早一笔已结算记录日期，结束取今天。
  • 选中自定义后，四个预置项全部取消高亮，互斥。

总览卡

  • 大字为总盈亏 = 买单盈亏 + 卖单盈亏，两者量纲一致可相加。
  • 投注额与押金不可相加，不设「总投入」这类合并指标。
  • 底部细字为当前时点快照，展示待结算与进行中，不随时间筛选变化——这些单据尚无结算时间，落不进任何区间。

按日表格

  • 四列：日期 / 买单输赢 / 卖单盈亏 / 合计。合计行固定在表头下方。
  • 只列出产生过结算的日期，无结算的日期不占行；按日期倒序。
  • 某列当日无数据时显示 0，不用破折号。
  • 展开为单开：点第二天时第一天自动收起；切换时间区间时展开态清空。
  • 当日无买单则隐藏买单分组，无卖单则隐藏卖单分组，两组都在时才显示中间分隔线。

展开层与跳转

买单分组：买单笔数 / 投注金额 / 平台抽佣。

查看当日买单 ›
跳转至买单 → 已结算，时间筛选自动设为该日期（自定义态，起止同为当天）。买单页自定义筛选按结算时间过滤，与报表口径一致。

卖单分组：卖单笔数 / 已收单金额 / 平台抽佣。

查看当日卖单 ›
跳转至我的卖单，时间筛选自动设为该日期，筛选行右侧出现「MM-DD ✕」胶囊，点叉清除回到全部时间。状态筛选同步重置为「全部」，避免因状态不匹配显示空列表。

货币

  • CNY 用 ¥，USD 用 $，VND 用 ₫。符号位于正负号之后，如 +¥319.95、-¥1.20、¥0.00。
  • VND 无辅币单位，按整数展示，不带小数位。
  • 取会员账户币种。一名会员仅持有一种币种，不存在跨币种汇总，报表无需按币种分列。
  • 原型中点击「我的」页余额旁的币种标签可循环切换，仅供演示，非产品功能。
  • 货币符号仅在本页生效，报表外的页面统一展示 CNY。
