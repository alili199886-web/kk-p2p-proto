算钱口径
  1. 单关模式下同玩法复式的最高奖金由「取最大值」改为「逐注求和」。
  2. 过关方式 M串N 的 N 只统计关数组合数 C(M,k)，复式倍增单独作为「注数」表述，不再出现「2串2」这类不存在的过关方式。
  3. 新增余额校验：投注金额超过可用余额时置灰并提示，另加单笔投注金额上限 2,000,000。
  4. 奖金上限由「一刀切 200 万且禁止下单」改为按关数分档（单关 500 万 / 2–3 关 20 万 / 4–5 关 50 万 / 6 关 100 万），超出只提示「超出部分不派奖」，不拦截下单。
  5. 让球／让分数带入投注结果弹窗，与投注单、注单卡共用同一套盘口与选项文案函数。
状态与流程
  1. 切换球类时若投注单含另一球类选项，弹二次确认后清空，不再静默保留。
  2. 已结算的时间范围筛选生效，按结算时间过滤，列表与汇总同时联动。
  3. 关数可全部取消，「过关选择 / 金额 0 / 立即投注置灰」成为可达状态。
  4. 关数网格下方常驻上限说明，写明当前投注单可用最高关数、原因与本球类可投场次。
  5. 状态跳转带出的 toast 纳入统一定时清除。
  6. 新增封盘态：封盘场次置灰、不可选、不计入分组头与联赛筛选的可投场次数。
  7. 注单状态补全「已退款 / 已作废」，并补两条样例——单关赛事取消全额退款、串关取消场次按 1.00 计算。
数据一致性
  1. 赛事日跨午夜的场次统一加「次日」前缀，并按赛事日推导真实开赛日期。
  2. 注单号与投注时间对齐（原 U1／U2 差 8 分钟）。
  3. 注单赔率与赛事池对齐，并新增「赔率类型：下单锁定赔率」独立字段说明快照语义。
  4. 投注时间后拼接的「（欧洲盘）」移出，改为赔率类型字段。
  5. 联赛筛选由联赛名改为联赛 ID 作为键。
  6. 基础金额默认由 1000 元改为 10 元；含比分／胜分差被锁定后，移除该选项会恢复用户原先档位。
  7. 说明页映射修正（篮球大小分不再落到胜分差页），「重置原型」同时重置赛事日与明细展开态。
决策清单（已全部确认）
入口与列表
  1. 竞彩入口：复用「体育赛事」大卡 → 游戏大厅 → 竞彩厂商卡；九宫格「彩票」去掉点击事件。
  2. 列表分组：按开赛时间的自然日分组，分组头不加「今日／明日」字样；赛事日（期次）另存，仅用于编号域与结算归属。
  3. 赛事日来源：由后端接口返回，前端不限制天数。
  4. 封盘：时间由三方数据源推送；封盘后赛事从列表移除，投注单内已选项标红「封盘，不可投注」并阻止下单。
  5. 单关资格：不做限制，所有盘口一律可单关，列表不再有「单」角标。
  6. 符号释义：让球位数字仅写进需求说明，界面不做图例。
投注与计算
  1. 关数与场次：不分玩法，统一最高 8 关、最多 8 场，超出提示「最多选择8场赛事」。
  2. 足篮混串：不允许，切换球类需二次确认后清空投注单。
  3. 倍数与注数：倍数折算进注数，展示注数 = 组合注数 × 倍数，注单卡不出现倍数字段。
  4. M串N 命名：N 只统计关数组合数 C(M,k)，复式不并入 N，统一表述「M串N · 共 X 注」；投注面板第三格固定显示「过关选择」。
  5. 派奖封顶：按官方分档，单场 10 万 / 2–3 场 20 万 / 4–5 场 50 万 / 6 场及以上 100 万，逐注封顶、不拦下单。
  6. 投注限额：单张彩票上限 20,000 元，每注最低 2 元（默认档位 10 元）；余额不足在下注时 toast「余额不足，请充值。」
  7. 基础金额：七档配置下发，默认 10 元，不支持手动输入。
  8. 结算口径文案：玩法展开后不展示，只写进需求说明。
注单与结算
  1. 状态口径：待结算 / 赢 / 输 / 已退款 / 已作废，逐场标记同为赢 / 输 / 作废。
  2. 部分结算：放在「未结算」分组下，整单仍为待结算，已完赛场次直接出赛果与赢／输标记，不加额外提示文案。
  3. 结算时机：本期不做提前结算，串关等全部场次完赛后统一结算。
  4. 逐注明细：不做。
  5. 时间范围：已结算按投注时间筛选，今日 / 昨天 / 7天 / 30天，列表与汇总联动。
  6. 无效场次：单关全额退款；串关该场赔率置 1.00、按剩余场次继续结算。
  7. 点击分析：按竞品做官方投注比例两行表格。
